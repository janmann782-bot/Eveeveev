# Бот обращений Тимофея Рализма (2060–2062)

Telegram-бот: генерирует и постит обращения Рализма. Можно **загружать любой текст и файлы** в контекст модели.

## Контекст (главное новое)

Админ может наполнить бота лором:

1. **Прислать файл** в личку боту: `.txt` `.md` `.docx` `.pdf` `.json` `.csv` и др.  
   Текст извлекается и сохраняется в `ralizm_context/`.
2. **`/context_add текст…`** — добавить кусок текста.
3. Ответить **`/context_add`** на любое сообщение с текстом — оно попадёт в контекст.
4. **`/context`** — список загруженного.
5. **`/context_clear`** — очистить всё.
6. **`/context_export`** — скачать сводку контекста файлом.

Всё это подмешивается в system prompt при каждой генерации (лимит ~80k символов, свежие файлы в приоритете).

Для PDF: `pip install pypdf` (опционально). DOCX читается без доп. пакетов.

## Остальное

- Автопост с редактируемым интервалом (`/interval`)
- Размер ответа (`/tokens`, по умолчанию 512)
- `/post` и `/post тема`

## Установка

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
# опционально для PDF:
pip install pypdf
```

`.env`:

```
TELEGRAM_TOKEN=...
OPENROUTER_API_KEY=sk-or-v1-...
CHANNEL_ID=-1004341947372
ADMIN_ID=7787565361
POST_INTERVAL_HOURS=1
MAX_TOKENS=512
OPENROUTER_MODEL=deepseek/deepseek-chat-v3-0324:free
```

```bash
python bot.py
```

## Команды админа

| Команда | Действие |
|---------|----------|
| `/start` | Справка |
| `/status` | Статус + список контекста |
| `/key` `/model` `/models` | API и модель |
| `/tokens N` | max_tokens |
| `/interval H` | интервал автопоста (часы) |
| `/post [тема]` | пост в канал |
| `/context` | что в контексте |
| `/context_add …` | добавить текст |
| `/context_clear` | очистить контекст |
| `/context_export` | выгрузить контекст |
| *файл в чат* | загрузить в контекст |
