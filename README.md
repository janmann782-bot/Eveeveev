# Бот обращений Тимофея Рализма (2060–2062)

Telegram-бот, который по интервалу (и по команде админа) генерирует и постит в канал обращения президента САР Кефирстан в стиле после поражения в Йогуртстанской войне, после Кефирского мятежа, на фоне Фонда Национального Выбора, ЧВК «Чёрные Огни» и тотального договорного пиздеца.

## Что умеет

- Автопостинг с **редактируемым интервалом** (по умолчанию 1 час) в канал `-1004341947372`
- Редактируемый размер текста (`max_tokens`, по умолчанию **512**)
- Команда `/post` — только от админа `7787565361`
- `/post тема` — обращение на конкретную тему
- `/status` — статус
- Максимальный реальный контекст из хроник: Рализм, Фонд, мятеж 12–23 марта 2059, Йогуртстан 2057–2060, Молозорь, Твороград, СВД, Турбания, Дервесния, «Чёрные Огни», Матвей Нис, Каирда, Ланев, «Фонд без выбора» и т.д.

## Стиль

Холодный договорной язык + маты + абсурд + цинизм.  
Фразы вроде «умойтесь в унитазе», «добровольный выбор», «не подписываю воздух», сравнения с сыром, канализацией и накладными.

## Установка

```bash
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

Создай файл `.env`:

```
TELEGRAM_TOKEN=токен_бота_от_BotFather
OPENROUTER_API_KEY=sk-or-v1-...
CHANNEL_ID=-1004341947372
ADMIN_ID=7787565361
POST_INTERVAL_HOURS=1
MAX_TOKENS=512
OPENROUTER_MODEL=deepseek/deepseek-chat-v3-0324:free
```

**Важно:**
1. Бот должен быть **админом** канала (право писать сообщения).
2. Ключ OpenRouter вида `sk-or-v1-...`.
3. `MAX_TOKENS=512` — размер ответа (контекстное окно генерации). Можно менять командой `/tokens`.
4. `POST_INTERVAL_HOURS` — интервал автопоста в часах (можно дробный: `0.5` = 30 минут).

## Запуск

```bash
python bot.py
```

После старта через ~1 минуту уйдёт первый автопост, дальше — по заданному интервалу.

## Команды (только админ)

| Команда              | Что делает                                      |
|----------------------|-------------------------------------------------|
| `/start`             | Справка                                         |
| `/status`            | Статус (ключ, модель, interval, tokens)         |
| `/key sk-or-v1-...`  | Поставить/сменить OpenRouter-ключ               |
| `/model <id>`        | Сменить модель                                  |
| `/models`            | Список рекомендуемых моделей                    |
| `/tokens <N>`        | Размер текста (max_tokens), напр. `/tokens 512` |
| `/interval <часы>`   | Интервал автопоста, напр. `/interval 0.5`       |
| `/post`              | Сгенерировать и сразу в канал                   |
| `/post <тема>`       | То же, но с заданной темой                      |

Примеры:
```
/tokens 768
/interval 2
/post Фонд Национального Выбора и долги после войны
/post Остатки ЧВК на востоке Йогуртстана
/post Почему Молозорь уже не молчит
```

Настройки `MAX_TOKENS`, `POST_INTERVAL_HOURS`, `OPENROUTER_MODEL`, `OPENROUTER_API_KEY` пишутся в `.env` и переживают перезапуск.
