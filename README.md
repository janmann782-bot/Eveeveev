# Бот обращений Тимофея Рализма (2060)

Telegram-бот, который раз в час (и по команде админа) генерирует и постит в канал обращения президента САР Кефирстан в стиле 2060 года: после поражения в Йогуртстанской войне, после Кефирского мятежа, на фоне Фонда Национального Выбора, ЧВК «Чёрные Огни» и тотального договорного пиздеца.

## Что умеет

- Автопостинг **раз в час** в канал `-1004341947372`
- Команда `/post` — только от админа `7787565361`
- `/post тема` — обращение на конкретную тему
- `/status` — статус
- Максимальный контекст из хроник: Рализм, Фонд, мятеж 12–23 марта 2059, Йогуртстан 2057–2060, Молозорь, Твороград, СВД, Турбания, Дервесния, «Чёрные Огни», Матвей Нис и т.д.

## Стиль

Холодный договорной язык + маты + абсурд + цинизм.  
Фразы вроде «умойтесь в унитазе», «добровольный выбор», «не подписываю воздух», сравнения с сыром, канализацией и накладными.

## Установка

```bash
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

Скопируй `.env.example` → `.env` и заполни:

```
TELEGRAM_TOKEN=токен_бота_от_BotFather
GEMINI_API_KEY=твой_ключ_OpenRouter   # пример уже стоит, замени
CHANNEL_ID=-1004341947372
ADMIN_ID=7787565361
```

**Важно:**
1. Бот должен быть **админом** канала (право писать сообщения).
2. Ключ OpenRouter — из Google AI Studio (https://aistudio.google.com/).  
   С 2026 года ключи начинаются на `sk-or-v1-` — это нормально. Бот уже на новом SDK `google-genai`, который их понимает.
3. Модель по умолчанию: `openrouter-2.0-flash`. Можно поменять в `bot.py`.

## Запуск

```bash
python bot.py
```

После старта через ~1 минуту уйдёт первый автопост, дальше — каждый час.

## Команды (только админ)

| Команда          | Что делает                          |
|------------------|-------------------------------------|
| `/start`         | Справка                             |
| `/status`        | Статус                              |
| `/post`          | Сгенерировать и сразу в канал       |
| `/post <тема>`   | То же, но с заданной темой          |

Пример:
```
/post Фонд Национального Выбора и долги после войны
/post Остатки ЧВК на востоке Йогуртстана
/post Почему Молозорь уже не молчит
```
